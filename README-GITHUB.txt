FIRST PERSON BOXER - GitHub Pages upload notes
==============================================

These files go at the TOP of your repository rwliu129/first-person-boxer (index.html in the main folder,
not inside a sub-folder). The game is then at https://rwliu129.github.io/first-person-boxer/

Updating later: upload the new files over the old ones (same names, same folders). One file's name changes
between versions (assets/impacts-XXXXXXXX.wav, named after its contents); deleting the old one is optional.

Online PvP uses https://first-person-boxer-server.onrender.com (set in config.js). Nothing else to configure,
unless your Render server has ALLOWED_ORIGINS set: then add https://rwliu129.github.io to it.

.nojekyll (an empty file) tells GitHub to serve the files exactly as they are. It's optional.
VERSION.txt says which version these files are.
